# 教师节贺卡网站

「祝董老师教师节快乐」动画贺卡页（学生：姜山），源自 GitHub 仓库 [yishuier/teacher](https://github.com/yishuier/teacher)。

- 网站入口：https://ginger815.github.io/teacher/ （自动跳转到 `html/index.html`）
- 彩蛋：在首页输入姓名「董晓晶」并点击按钮进入彩蛋页面
- 已知缺失：彩蛋页背景音乐 `radio/儿歌 - 虫儿飞.mp3`（原仓库未包含），如需使用请自行补充

## 本地运行

下载本仓库后，在仓库根目录执行：

```sh
npx serve .
```

或直接用任意静态文件服务器托管本目录。
